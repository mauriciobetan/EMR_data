# Input Directory

This directory contains the links to obtain the unedited data files directly from the sources.

1. Birds census (1908-2008). From Salvatteci 2018: https://doi.pangaea.de/10.1594/PANGAEA.888403?format=html#download

2. Anchoveta catch, 1950-2024. From FAO. (country = 'Peru', ASFIS species = 'Anchoveta(=Peruvian anchovy)'; years = 1950-2024) : https://www.fao.org/fishery/statistics-query/en?dataset=capture&timeseries=capture_quantity

3. Anchoveta biomass (SSB). From Oliveros-Ramos, p. 306-307: Oliveros-Ramos, R. (2026). Un nuevo modelo para estimados poblacionales de la anchoveta peruana (Engraulis ringens) usando una dinámica por frecuencias de tallas. In J. Csirke & R. Guevara-Carrasco (Eds.), La Anchoveta peruana (Engraulis ringens). Stock Norte-Centro (1950-2009): Construyendo las Bases Científicas para un Enfoque Ecosistémico: I (pp. 289–307). Instituto del Mar del Perú. (Available online at: https://repositorio.imarpe.gob.pe/items/186a4e9e-81ca-4ce2-a2dd-c4590536370a)

4. AGRORURAL birds census available upon request. AGRORURAL'S transparency portal: (https://www.transparencia.gob.pe/reportes_directos/pep_transparencia_acceso_informacion.aspx?id_entidad=13860&id_tema=49&cod_rueep=0&ver=)
